# Get Path to FastDup Binary Directory

Get Path to FastDup Binary Directory

## Usage

``` r
fastdup_bin_dir()
```

## Value

A character string containing the FastDup binary directory, or an empty
string when it is unavailable.

## Examples

``` r
fastdup_bin_dir()
#> [1] "/home/runner/work/_temp/Library/RBCFTools/fastdup/bin"
```
